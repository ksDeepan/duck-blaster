# 🦆 Duck Blaster — Flying Duck Shooting Arcade Game

A fun, browser-based duck shooting arcade game built with **HTML, CSS, and JavaScript**. Aim carefully, shoot flying ducks, earn points, and progress through increasingly challenging levels!

## 🎮 Play Online

**[▶ Play Duck Blaster](https://ksDeepan.github.io/duck-blaster/)**

No installation required to play online. Open the link in your browser and start playing!

## ✨ Features

- 🦆 **Duck Shooting Gameplay** — Aim and shoot moving ducks.
- 📈 **10 Levels** — Progress through increasingly challenging stages.
- 🏆 **Scoring System** — Earn points for every duck you hit.
- 🌟 **Golden Ducks** — Shoot special golden ducks for bonus points.
- ⏱️ **60-Second Timer** — Score as many points as possible before time runs out.
- ❤️ **Lives System** — Keep playing while you have lives remaining.
- 🔫 **Ammo and Reloading** — Manage your ammunition during gameplay.
- ⏸️ **Pause and Resume** — Pause the game whenever needed.
- 🔊 **Sound Controls** — Enjoy game audio with the sound feature.
- 💾 **High Score** — Save your best score in the browser.
- 🌐 **Browser-Based** — Play without installing additional software.

## 🚀 Run Locally

You can run Duck Blaster on your own computer.

### Prerequisites

- A modern web browser such as Chrome, Edge, or Firefox.
- Python installed if you want to use the local HTTP server.

### 1. Clone the repository

```bash
git clone https://github.com/ksDeepan/duck-blaster.git
```

### 2. Open the project folder

```bash
cd duck-blaster
```

### 3. Start a local web server

```bash
python -m http.server 8000
```

If your system uses the `python3` command, run:

```bash
python3 -m http.server 8000
```

### 4. Open the game

Visit this address in your browser:

```text
http://localhost:8000
```

To stop the server, press `Ctrl + C` in the terminal.

**Alternative:** You can also open `index.html` directly in your browser, although using a local server is recommended.
